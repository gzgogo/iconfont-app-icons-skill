# Security policy

## Sensitive data

Never attach iconfont cookies, browser storage-state files, browser profiles, authenticated request dumps, or application secrets to an issue or pull request.

The Skill stores its session outside application repositories and masks credential values in command output. If you suspect credential exposure, revoke the iconfont session by logging out, remove the local session file, and log in again.

## Reporting a vulnerability

Use GitHub's private security advisory feature for this repository. Include reproduction steps with synthetic credentials only.
